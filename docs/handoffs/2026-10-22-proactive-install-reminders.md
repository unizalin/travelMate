# 主動安裝與今晚提醒交接

- 成員「我的待辦」新增安裝→今晚提醒鏈；依使用者先前明確移除頁首注意卡的決策，不把整張「出發前先注意」放回行程。此處不是 45 項共用行李範本。
- standalone 共用 auroraPushService 原判定（display-mode／navigator.standalone）。一般網頁只提示安裝，Safari 分享→加入主畫面→從圖示開啟，並提醒 LINE 無法安裝。Chrome 若實際捕捉 beforeinstallprompt 才提供系統安裝按鈕，否則顯示選單步驟。
- standalone、10/30–11/6、未啟用今晚提醒才出第 2 項；點按會切冰島行程並展開極光詳情的今晚提醒設定。啟用後以既有 status 查詢確認隱藏，隔晚到期重新出現。
- 沿用既有 PushState；每分鐘、視窗回前景與訂閱操作後刷新。保留 AuroraReminderSettings 內既有被動說明文字。非成員沒有「我的」頁，不載入裝置提醒。
- 純規則測試包含非 standalone 僅安裝、standalone 僅今晚、已啟用兩項皆無、非成員皆無、期間外不出今晚；成員頁元件測試覆蓋待辦操作。
- 外部驗收尚待：iPhone Safari 第 1 項 → 安裝並從主畫面開啟後第 1 項消失 → 旅行期間出第 2 項 → 訂閱成功後消失。正式推播憑證與排程仍受阻，不能以待辦完成實作宣稱已能收到通知。
