# 三部分收尾執行紀錄

唯一範圍：使用者附件三部分要求。依推播上線→主動安裝／今晚提醒→我的頁整理執行；權限阻擋時記錄後繼續下一部分。

1. 正式推播：保留本機 makePushHandler 與 checkSubscribers，新增私有 Supabase 儲存與受鎖保護的 Functions adapter；所有正式金鑰僅以環境變數注入。核對 Vercel 登入／方案；不能取得權限則不建立假設定。新增 migration 本機 PostgreSQL 通過後立即套用雲端。排程必須受 CRON_SECRET 保護。
2. 主動提醒：共用 standalone 與既有推播查詢，加入成員個人待辦。安裝提示與今晚開啟鏈依裝置／日期／狀態切換，不進行李範本。
3. 我的：固定順序身分→待辦→航班→記帳→邀請→帳號與裝置；移除整段攝影偏好與收藏接線，活動拍攝建議固定保留。帳號／離線／通知狀態直接顯示。記帳僅調整呈現。

全部指定關卡通過才走獨立提交→乾淨整合 main→Vercel。需三份交接或同一份三節，兩處同步；真人驗收不能以測試取代。
