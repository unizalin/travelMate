# 共同旅費記帳與分帳

使用者已選擇共同記帳＋分帳，入口位於「我的→旅費記帳」，維持四個主分頁。新版沿用現有品牌與單頁版面，私人成員以外不能讀寫。

## 本次功能

- 成員新增支出：日期、項目、GBP／ISK／TWD、金額、付款身分、參與平分身分；不假設每筆都六人共同負擔。
- 金額以整數最小單位儲存；餘數確定分配，分攤加總等於原支出。
- 各幣別獨立顯示總支出與建議還款，不混用匯率。
- 登記已還款是記錄實際還款，不執行任何金流。
- 所有成員可讀；建立紀錄者或旅程建立者可修改／作廢。作廢保留資料，修訂檢查版本以免覆蓋他人更新。
- 名單來自每列 journey，支援尚未認領的身分參與分攤；一般登入不取得讀寫權。解除認領後立即回收雲端存取。

## 實作與驗證順序

1. 建立獨立 ledger domain、整數分攤／餘額／建議還款測試。
2. 新 additive migration：journey 外鍵、RLS、原子儲存 RPC、版本檢查、作廢。既有費用與其他旅程資料不改寫。
3. 本機 PostgreSQL 實跑成員／非成員、跨旅程、精確分攤、並行版本與作廢；通過後當天套用雲端，不把 migration 留到最後。
4. 私人成員 service 解析 RPC；My 內以可展開區塊承載明細與表單，儲存成功才更新畫面。斷線時禁止寫入並提示重新連線。
5. 公開隔離加入 ledger 元件／服務；元件與 service 測試後跑既有全部關卡。
6. 更新主專案與 worktree 交接及主 CONTEXT，獨立提交，乾淨整合 main→Vercel，外部核對部署。
